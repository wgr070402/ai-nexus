1项目定位

以 Operit AI（系统自动化 + 完整 Linux 终端）、RikkaHub（多模型聊天体验）、拾忆 ShiYi（记忆 / 项目 / 技能 / 子代理）三者之长，合成一个 Android 应用：

  • 打开即聊天：启动直达单聊界面，随手切模型。
  • 多智能体群聊：一个会话里混入「模型 / 智能体 / 专家」，最多 10 个，支持并行与讨论两种模式。
  • Operit 同款终端：内置完整 Linux（proot Ubuntu 24.04），开箱即用。
  • 四引擎：本地/云端模型 + DeepSeek Harness + Codex + Codex++，并列可选。
  • 环境状态检测：终端配置后自动检测 Python/Node/Shell/DeepSeek Harness/Codex 状态（运行中/未配置/配置失败）。

3技术栈与决策（已确认，勿推翻）

项选型理由
框架Flutter + Dart（Material 3）需求文档明确「Flutter / Android」

9环境要求与编译

关键约束：本项目的开发环境（手机端）只有 Node，没有 Flutter SDK。因此代码编写在此完成，但编译打包 APK 必须在装有 Flutter SDK 的电脑端执行。

电脑端准备

  1. 安装 Flutter SDK（https://flutter.dev）+ Android Studio / Android SDK。
  2. 将本目录 ai-nexus/ 拷贝到电脑。
  3. 执行：
flutter pub get      # 拉取依赖
flutter run          # 调试运行（连真机或模拟器）
flutter build apk    # 打包 APK
